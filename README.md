# Brīvdienu māja „Joki”

Teksti ir failā `index.html`. Tur labo virsrakstus, rindkopas un pogu nosaukumus. Maini vārdus starp zīmēm `<` un `>`. Tās zīmes atstāj, kā ir.

Labojot saglabā latviešu burtus (ā, č, ē, ģ, ī, ķ, ļ, ņ, š, ū, ž). Fails ir UTF-8. Nemaini to uz citu kodējumu.

Kad teksti ir gatavi, pasaki G, lai publicē.

Rezervācijas forma ir tikai demonstrācija. Tā neapstiprina rezervāciju un nesūta pieteikumu.
